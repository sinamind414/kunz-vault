# Kunz El Ouloum — Vault partagé

Vault Obsidian dédié au projet **Kunz El Ouloum**.
Il sert de **source de vérité** pour les décisions, la architecture, les logs des bots et les références SVT.

## Règles d’accès
- **Notes humaines** (`PAR/`, `sources/`) → lecture seule pour les bots
- **Notes IA** (`inbox/`, `daily/`, `agent-os/`, `memories/decisions/`) → lecture/écriture
- **Méthodologie** : `AGENTS.md` du vault précise les chemins autorisés par bot

## Structure
- `PAR/` : Projects / Areas / Resources / Archive
- `inbox/` : notes brutes des bots
- `daily/` : logs quotidiens
- `memories/` : décisions et leçons
- `agent-os/` : règles, skills, logs bots
- `sources/` : références officielles SVT
